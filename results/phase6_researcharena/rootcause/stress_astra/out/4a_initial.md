# 4a — alternatives recorded before A.1
Paths below are relative to pinned task_context unless specified. These are candidate mechanisms, not claims of GPU confirmation.

- **RoPE rounded block tail** (high confidence source bug): rotary_embedding.cu:24-34 never checks idx; launcher :68-70 rounds to 256. Separate k has only 128 pairs for B=S=1,H=4,D=64. Distinguish from shared-head hypothesis by enumerating each launch and memcheck on isolated k. This is a different RoPE cause, not an alternative kernel.
- **Attention OOB on unexpanded GQA**: attention.cu:34,61,129 uses grid query heads for K/V offsets; :144-155 no K-head validation. Distinguish by hooks at actual ops.attention, not just RoPE. Existing attention probe reports expanded heads, making this unlikely on this path.
- **Attention partial-warp reduction UB**: attention.cu:71-72,85-87,102-103,111-112 use full mask but :154 launches min(kv_len,256), possibly <32 or non-warp-aligned. Test lengths 1,2,13,31,32,33,255,256 against torch SDPA; sanitizer synccheck and numerical checks. Numerical errors alone need not explain illegal address.
- **dtype mismatch**: RoPE :72-77 dispatches x dtype but hard-casts positions to int; attention :157-164 dispatches Q alone; RMSNorm :77-83 input alone. Log actual tensor dtypes; mixed dtype normally raises on typed data_ptr rather than silently reinterprets. fp16 accumulation vs float precision is accuracy, not generally an address fault.
- **wrapper layout/ownership**: inject.py:162-167 contiguous transpose in, permuted output out; RoPE :61 clones (owned storage); attention :151 empty_like. Verify strides/storage spans/lifetime and synchronization. No raw dangling pointer evident; returned Tensor owns clone. Expanded batch positions :159-161 are not contiguous for B>1, unlike current B=1.
- **grid/block/resource overflow outside RoPE**: attention :153-155 grid.z=q_len and shared memory=(kv_len+D)*4; RMSNorm :74-75 hidden-sized block; fused_mlp :45-48 int numel. Log launch dimensions and device limits; large shape invalid launch differs from memcheck OOB. Current short TinyLlama shapes do not approach integer or shared-memory limits.
- **sequence/position mismatch**: inject.py:158-161 resets positions to 0 on every decode, ignores supplied cos/sin; kernel :44-45 rotates adjacent pairs instead of Llama half-vector pairs. Compare nonzero-position output to HF. Likely correctness bugs independent of the crash; true context positions need not cause OOB with valid launch.
- **cos/sin cache too short**: inject.py:156-165 ignores cos/sin entirely. Native fallback :169 may use them. Hook lengths and fallback counters; force strict exceptions. Not direct custom kernel input in stock.
- **cache implementation bug**: debug8/p6_diag_bench_blocking.log traceback points at cache_utils.py:557 cat, not necessarily origin. C0 with identical shape/dtype/cache, explicit sync after each custom op, isolated cache update and stock-vs-native RoPE distinguish. Blocking is insufficient because inject.py:168 catches the original custom-op exception.
- **earlier RMSNorm or previous-layer MLP corruption**: RMSNorm :22-30,:60-64 row/hidden indexing; fused_mlp :21-29 bounds checked. Unit memcheck all custom ops and per-op synchronize. Lower likelihood from source, not ruled out by a later cache traceback.
- **wrong stream/device**: all four stock launches omit stream and CUDAGuard (e.g. RoPE :75). Nondefault streams or multidevice execution can race allocator/torch ops. Reproduce on default vs nondefault stream, log current device; current single-device default benchmark makes this less likely.
- **fallback masks original failure / no kernel actually exercised**: inject.py:124-130,168-169 broad except; subsequent cat may see sticky CUDA error. Strict diagnostic proxy synchronize inside each op and rethrow outside wrapper, record call counts; never treat INJECTED alone as executed.
- **global monkey-patch contamination**: inject.py:148-172 module-global patch and restore_model :214-220 is a no-op; reloading model doesn't restore function. bench.py:226-250 baseline then agent in same process can nest patches. Fresh process per arm, no cached baseline; compare one-vs-two loads.
- **stale extension/cache or wrong source arm**: bench.py:190-194 trusts cached scalar TPS; compilation :117ff and compile.py:24 build identity. Hash sources, unique build dirs/module names; assert all symbols and injection counts.
- **CUDA/driver/runtime/toolchain/hardware problem**: same error could be external (ABI mismatch, bad binary, ECC/Xid). C0, trivial sanitizer known-good/known-bad tests, versions, nvidia-smi and GPU process health distinguish. CPU cannot exclude these.
- **mask/scale ignored**: inject.py:107-123 forwards only is_causal, dropping attn_mask/dropout/scale on custom path. Compare padded/unpadded and supplied mask; accuracy bug (possibly NaN), not plausible direct memory indexing fault.
